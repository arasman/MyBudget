# Slide screenshots

Source of truth for the TFM slide deck's screenshots. Generated by Playwright,
not hand-captured, so every image reflects the real running app.

## Regenerate

From `Project/frontend`, with the Docker Compose stack running (API in
`ASPNETCORE_ENVIRONMENT=E2E`, frontend dev server up):

```bash
pnpm e2e:slides    # runs e2e/screenshots/*.spec.ts, writes PNGs + .manifest.json
pnpm slides:index  # rebuilds this folder's index.md + each flow's index.md
```

## Layout

```
docs/slides/flows/
  index.md                        <- generated, master index in slide-build order
  <flow-name>/
    01-<step>.png ...              <- sequenced screenshots
    .manifest.json                 <- generated, source data for index.md
    index.md                       <- generated, per-flow reference with descriptions
```

These images feed `../presentation/` — see `../README.md` for how the two fit together.

`index.md` is up to date once the flow's spec has been run — always re-run
`pnpm slides:index` after adding/editing screenshot specs.
